# txtpack

`pack.bat` рекурсивно переименовывает все файлы папки в `.txt`, сохраняя структуру подпапок,
и складывает дерево в `out\<папка>.zip`. Карта исходных имён — `extensions.txt` — внутри архива.

`unpack.bat` смотрит **только в `out`**: каждый архив распаковывается в `out\<имя архива>\`
с возвратом исходных имён и структуры. Конфиг ему не нужен.

Нужен Python 3.8+ и `python` в PATH.

## Настройка (только для pack)

В `config.ini` укажите папку:

```ini
path=D:\Photos
```

Подойдёт и относительный путь от папки утилиты; аргумент перекрывает настройку:
`pack.bat "D:\Photos"`.

## Запуск

1. `pack.bat` — файлы в папке станут `.txt`, в `out` появится `<папка>.zip`
   с той же структурой (`Фото\sub\a.txt`).
2. `unpack.bat` — все архивы из `out` распакуются в `out\<имя архива>\` с исходными именами.
   Исходные папки не трогаются.

Итог в `out`:

```
out\
  Фото.zip
  Фото\        <- распакованное, с исходными именами
```

Повторный `pack.bat`, когда в папке уже только `.txt`, отказывается работать —
удалите `out\<папка>.zip`, чтобы упаковать заново.

Файлы самой утилиты (`pack.bat`, `unpack.bat`, `txtpack.py`, `config.ini`, `README.md`)
в папке не переименовываются — иначе её не запустить, — но в архиве лежат как `.txt`.

## Формат extensions.txt

В каждой строке `новое_имя<TAB>исходное_имя`, пути относительные:

```
a.txt	a.jpg
sub\a.txt	sub\a.jpg
```

Занятые имена не перезаписываются: если рядом есть `a.jpg` и `a.png`, второй станет `a_1.txt`.
