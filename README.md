# txtpack

`pack.bat` собирает `out\<папка>.zip`: все файлы папки (рекурсивно) лежат в архиве
с расширением `.txt`, структура подпапок сохраняется. Карта исходных имён — `extensions.txt` —
внутри архива. **Исходная папка не изменяется.**

`unpack.bat` смотрит **только в `out`**: каждый архив распаковывается в `out\<имя архива>\`
с возвратом исходных имён и структуры.

Нужен Python 3.8+ и `python` в PATH.

## Настройка (только для pack)

В `config.ini` укажите папку:

```ini
path=D:\Photos
```

Подойдёт и относительный путь от папки утилиты; аргумент перекрывает настройку:
`pack.bat "D:\Photos"`.

## Запуск

1. `pack.bat` — в `out` появится `<папка>.zip`, внутри дерево с именами `*.txt`
   (`Фото\sub\a.txt`). Сама папка остаётся как была.
2. `unpack.bat` — все архивы из `out` распаковываются в `out\<имя архива>\`
   с исходными именами и структурой.

Итог в `out`:

```
out\
  Фото.zip
  Фото\        <- распакованное, с исходными именами
```

## Какие имена в архиве

Расширение заменяется на `.txt`: `a.jpg` → `a.txt`, `pack.bat` → `pack.txt`.
Если рядом уже есть `a.txt`, станет `a_1.txt`; файлы, которые и так `.txt`, остаются как есть.

## Формат extensions.txt

В каждой строке `новое_имя<TAB>исходное_имя`, пути относительные:

```
a.txt	a.jpg
sub\a.txt	sub\a.jpg
```
